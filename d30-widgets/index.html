D30 Widgets

A Unity plugin for iOS and Android home-screen widgets. You lay the widget out in an editor window and change it from game code.

The native side gets generated when you build, so there's no Swift or Kotlin to write.

Asset Store · soon Help

What you get

Widget Editor
Images, text, timers, progress bars and PNG-sequence animations, arranged on layers. Preview mode puts the widget on a simulated iPhone or Android home screen.
Build step
On iOS it adds a WidgetKit extension and an App Group to the Xcode project. On Android it adds the widget resources and a small runtime.
C# API
You change elements through string keys like Energy/Count. An edit can apply right away or at a set time, and timed ones still land if the game is closed.
Taps
A tap opens the game, and you get the slot, the widget and a payload you set per element.
Samples
Six of them, see below.
Docs
Ship inside the package, in Documentation~.

The code

Each key is bound to an element in the editor. This updates the Energy Meter sample:

await Widgets.Edit()
    .SetText("Energy/Count", "3 / 5")
    .SetProgress("Energy/Amount", 0.6f)
    .SetCountdown("Energy/Full", fullAt)
    .Now();

// Shows up at fullAt, whether or not the game is running.
await Widgets.SetText("Energy/Status", "Energy full").At(fullAt);

Setup

  1. Open D30 > Widget Editor and create a widget.
  2. Give every element your game will change a key, for example Energy/Count. Static elements don't need one.
  3. In Project Settings > D30 > Widgets, tick the widget and add a slot for it.
  4. Call Widgets.Edit() from your game.
  5. Build. The widget shows up in the home screen's widget picker.
